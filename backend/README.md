# Aswani backend

This folder belongs to the backend team. Put the backend project here
(source code, its own README with how to run it, and an `.env.example`).

Rules:
- This repository is public: real secrets live only in `.env`, which is ignored.
  Commit an `.env.example` with the variable names and fake values.
- The API follows the contract in `docs/api-contract/`. Contract changes are
  agreed with the mobile team first, then versioned (v1.0, v1.1, ...).
